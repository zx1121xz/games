# 五子棋 · Gomoku

一个**纯前端**的五子棋小游戏：不依赖任何框架、不需要后端、没有构建步骤，克隆下来用浏览器打开 `index.html` 就能玩。

在线试玩：**<https://zx1121xz.github.io/games/>**（GitHub Pages）

## 功能

- 🎯 **人机对战**：三档难度（简单 / 普通 / 困难），可选执黑先行或执白后行
- 👥 **双人对战**：同一台设备上轮流落子
- 🤖 **AI 引擎**：棋型评分 + Alpha-Beta 剪枝 + 迭代加深 + 时间上限，困难档搜索深度可达 6 层
- ↩️ **悔棋 / 重新开始**：一键回到上一步或新开一局
- 🏆 **胜负判定**：横、竖、斜任意方向连成五子（含长连）即获胜，并高亮获胜连线
- 📊 **比分统计**：分别记录黑胜、白胜、和棋局数
- 🔊 **落子音效**：使用 Web Audio 合成，无外部素材，可开关
- 📱 **响应式**：电脑、平板、手机均可直接使用，棋盘随窗口自适应
- ⌨️ **快捷键**：`Ctrl/Cmd + Z` 悔棋、`R` 重新开始

## 本地运行

方式一：直接双击 `index.html`（或拖进浏览器）即可，所有功能都在本地运行。

方式二：起一个静态服务器（推荐，行为和线上一致）：

```bash
# 任选其一
python3 -m http.server 8000
npx serve .
```

然后访问 <http://localhost:8000>。

## 规则说明

- 15×15 棋盘，黑先白后，交替落子于交叉点；
- 横、竖、斜任意方向先连成五子（含五子以上长连）者获胜；
- 采用**无禁手**规则，不限制三三、四四、长连等开局禁手。

## AI 实现简介

- **棋型评分**：把每条直线转成字符串，按「连五 / 活四 / 冲四 / 活三 / 眠三 / 活二 …」的分值表匹配计分，并按强弱顺序消费已匹配棋型，避免重复计分；
- **增量维护**：每条线的分值和字符串按代缓存，落子/悔棋时只重算经过该点的 4 条线，评估函数为 O(1)；
- **候选点生成**：只考虑已有棋子附近（2 格 / 1 格）的空点，用「己方收益 + 对方收益」排序，深层收窄候选宽度；
- **搜索**：Alpha-Beta 剪枝 + 迭代加深（2/4/6 层），带时间上限（简单 150ms、普通 700ms、困难 1600ms），超时即返回上一层结果，保证界面不卡死；
- **即时战术**：搜索前先检查自己能一步成五、以及对手是否能一步成五，直接取胜或封堵。
